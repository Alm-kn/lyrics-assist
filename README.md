# Lyrics Assist

日本語の歌詞制作を補助する個人向けWebアプリのv0.1 β。

1つのキーワードから、以下の2軸をもとに候補語を10語提示する。

- 語感類似度
- 意味・文脈近接度

v0.1は完成品ではなく、候補選出とスコアリングの納得度を検証するβ版。
