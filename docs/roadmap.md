# 歌詞作成補助ツール Roadmap

更新日: 2026-08-11

この文書は、v0.1 βでは実装しないが、将来追加したい機能を管理する。
要件定義書と混同しないため、実装対象へ昇格するまでは本ファイルに置く。

## R-01 2軸重み付けバー
- UIイメージ: `語感類似度 <- ○ - ● - ○ - ○ - ○ -> 意味・文脈近接度`
- 5段階で生成・選抜の重みを変更する。
- 中央は 50:50。
- 暫定候補: 80:20 / 65:35 / 50:50 / 35:65 / 20:80。
- 各候補の語感スコア・意味スコア自体は変えず、生成探索と最終選抜の優先度だけを変える。

## R-02 部分韻 / フレーズ韻
- 例: `さよなら (aoaa)` と `後が無い (aoaa+i)`。
- 長さが異なっても一部分の母音パターンが一致するケースを扱う。
- v0.1では単語候補に限定し、この機能は切り離す。

## R-03 Preference Profile の自動反映
- Like / Dislikeなどから数値化した嗜好を更新。
- 語感重視度、意味重視度、意外性、抽象度、語長などを候補生成・選抜に反映。

## R-04 作詞用韻正規化の高度化
- Q（っ）とN（ん）の部分一致扱い。
- 歌唱時の発音差。
- 語固有・例外的な正規化ルール。
- strict / singing の複数比較モード。

## R-05 公開・複数ユーザー対応
- アカウント、同期、課金等は必要性が生じてから検討。
